# 🥗 Diet Tracker - 饮食追踪应用

一个功能完整的移动应用，帮助你每天记录饮食，追踪营养摄入和能量信息。

## ✨ 主要功能

- 📝 **每日饮食记录** - 轻松记录每一餐的食物和数量
- 🥗 **食物数据库** - 搜索和管理食物信息
- 📊 **营养分析** - 实时显示热量、蛋白质、碳水化合物、脂肪等营养成分
- 📈 **进度追踪** - 与每日目标对比，显示进度百分比
- ⚙️ **自定义目标** - 根据个人需求设置每日营养摄入目标
- 💾 **本地存储** - 使用 SQLite 数据库安全存储数据

## 🎯 功能详细说明

### 主页 (今日饮食)
- 查看今天的所有饮食记录
- 显示今日营养摄入总计
- 进度条展示与每日目标的完成度
- 快速删除饮食记录

### 添加食物
- **搜索现有食物** - 从食物库中快速查找
- **添加新食物** - 手动输入食物营养信息

### 统计分析
- 查看所选日期的详细营养数据
- 营养摄入进度条

### 设置
- 自定义每日营养目标
- 查看营养建议

## 💡 使用建议

### 营养摄入指南

**热量摄入**
- 女性: 1800-2200 kcal/天
- 男性: 2200-2800 kcal/天

**蛋白质**
- 推荐: 1.6-2.0g/kg 体重/天

**碳水化合物**
- 推荐: 总热量的 45-65%

**脂肪**
- 推荐: 总热量的 20-35%
